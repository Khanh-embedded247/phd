# Source Code

Thu muc `src/` chua code noi bo cua project Phenikaa.

Hien tai pipeline MapTR dung package:

```text
src/phenikaa_maptr/
```

Cac thu muc `dataset/`, `models/`, `pipelines/`, `utils/` duoc giu nhu khung Cookiecutter de phat trien sau. Code pipeline dang chay thuc te nam trong `scripts/maptr/`, con helper dung chung nam trong `src/phenikaa_maptr/`.
