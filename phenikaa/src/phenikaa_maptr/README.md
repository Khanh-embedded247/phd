# phenikaa_maptr

Package helper noi bo cho pipeline MapTR Phenikaa.

- `pipeline_config.py`: doc `configs/maptr/pipeline.yaml`, expand bien duong dan.
- `common.py`: helper dung chung cho cac script pipeline.

Cac script trong `scripts/maptr` tu them `${PHENIKAA_ROOT}/src` vao `sys.path`, nen co the chay truc tiep bang Python ma khong can cai package.
